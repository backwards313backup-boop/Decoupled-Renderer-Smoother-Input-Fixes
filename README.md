Fixes the stutter/laggy low sensitivity mouse input on desktop mode in Resonite when forcing the decoupled renderer enabled. By default it's un-useable on desktop and with this plugin it's now useable to obtain much higher FPS when CPU bottle necked. This also fixes the issues with menus/inventory/inspector scrolling being really slow as if you have 10 fps when the decoupler is enabled. 

This plugin requires Resonite Mod Loader.
